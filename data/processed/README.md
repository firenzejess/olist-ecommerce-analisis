# Datos procesados

Tablas generadas por el notebook `01_exploracion.ipynb` a partir de los datos originales de Olist. Son las que alimentan el dashboard de Power BI.

| Archivo | Una fila por | Contenido principal |
|---|---|---|
| `pedidos_entregados.csv` | Pedido entregado con reseña | Días de entrega, días de retraso, si llegó tarde, nota de la reseña y estado del cliente |
| `pedidos_categoria.csv` | Pedido y categoría de producto | Categoría, días de entrega, si llegó tarde y nota |
| `resumen_vendedores.csv` | Vendedor | Estado del vendedor, nº de pedidos, % de retrasos y nota media |
| `clientes_segmentos.csv` | Cliente | Recencia, nº de pedidos, gasto total, puntuaciones R y M, y segmento RFM |
